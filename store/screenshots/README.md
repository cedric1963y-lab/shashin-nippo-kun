# スクリーンショット

App Store に出す画像は、起動中の iOS シミュレータをそのまま PNG にしたものです。枠、キャッチコピー、スプラッシュの作り直し、購入画面の改変はしません。

この環境ではシミュレータを実行できないので、PNG はリポジトリに入っていません。Mac で次の4枚を撮ります。

| ファイル | 画面 |
| --- | --- |
| `raw/01-site-list.png` | ホームの現場一覧 |
| `raw/02-photo-add.png` | 写真を追加（メモと日時） |
| `raw/03-pdf-share.png` | 日報の作成、または iOS の共有シート |
| `raw/04-paywall.png` | プレミアム（月額と年額） |

アプリ内に PDF の専用プレビューはありません。3枚目は、実在する「日報を作る」画面か、共有シートです。

## 撮る前

1. Mac でシミュレータを起動する。Xcode が求める iPhone のサイズに合わせる。縦向き。
2. `flutter run` でこのアプリをそのシミュレータに入れる。StoreKit のローカル設定は Xcode の Run のときだけ有効です。購入シートまで撮る必要はなく、アプリのプレミアム画面で足ります。
3. サンプルの現場名と写真は、公開してよいものだけ使う。顧客の家や住所が写る写真は使わない。
4. 起動直後のスプラッシュは撮らない。

対象は iPhone のみです。iPhone のシミュレータ（縦）で撮ります。iPad の画面は不要です。

## 操作

ホームで「現場を追加」を押し、現場名を入れる。2件あると一覧らしい画面になります。無料プランの件数表示が上に出ている状態で1枚目を撮る。

```bash
tool/capture_app_store_screenshots.sh 01-site-list
```

現場を開き、「写真を追加」からライブラリの写真を選ぶ。タイトルが「写真を追加」の画面（写真、日時、メモ）で2枚目を撮る。システムの写真ピッカーではなく、その次のアプリの画面です。

```bash
tool/capture_app_store_screenshots.sh 02-photo-add
```

写真を保存し、「日報を作る」を開く。サイト名、日付、選ばれた写真、「PDFを作成して共有」が見える位置で3枚目を撮る。共有シートを開いた直後の画面でもよい。シートは iOS のものです。アプリに PDF ビューアは足していません。

```bash
tool/capture_app_store_screenshots.sh 03-pdf-share
```

ホームに戻り、上のプラン表示を開く。プレミアム画面の先頭（月額 ¥100 と年額 ¥1,200）が見える位置で4枚目を撮る。文章や価格を隠すためにスクロール位置を作らない。購入画面のコードは変えない。

```bash
tool/capture_app_store_screenshots.sh 04-paywall
```

スクリプトは起動中のシミュレータを `xcrun simctl io booted screenshot` で保存するだけです。ステータスバーの時刻も書き換えません。

アップロード前にトリミングやデバイス枠を足さないでください。App Store Connect が拒否するサイズなら、別のシミュレータで同じ4画面を撮り直します。
