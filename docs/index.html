写真日報くん

サポート

対象は iPhone アプリ「写真日報くん」（Bundle ID jp.shashinnippo.app）です。最終更新: 2026年10月7日。

一人で現場に入る方向けの写真日報です。撮った写真と短いメモを、その日の PDF にして共有します。アカウントはありません。

使い方

  1. 現場名を登録する。
  2. カメラか写真ライブラリから写真を追加し、必要なら短いメモと日時を残す。
  3. その日の写真を選んで日報 PDF を作り、iPhone の共有から LINE やメールへ渡す。

作った日報は、削除するまで何度でも共有できます。電子黒板や、会社の顧客管理、クラウド同期はありません。

無料とプレミアム

無料では日報 PDF を 3 件、写真を 20 枚までです。1 件の日報に入れられる写真は 30 枚までです。プレミアムは月額 ¥100、または年額 ¥1,200 の自動更新です。契約中は日報と写真の件数上限が外れます。期限が切れても、保存した現場・写真・日報は iPhone の中に残ります。広告はありません。

支払いや解約の条件は 利用規約 に書いてあります。

写真の扱い

写真日報くんは、現場の写真と日報をこの iPhone の中だけに保存します。運営のサーバーへは送りません。詳しくは プライバシーポリシー です。

連絡

アプリに問い合わせフォームはなく、運営のサーバーへメッセージを送る機能もありません。使い方はこのページと、アプリ内の「設定」に書いてあります。
